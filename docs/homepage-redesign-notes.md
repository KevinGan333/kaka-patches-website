# Homepage redesign — 14 October 2026

A review version inspired by Patches4Less's product-first navigation, visible quote entry points, application browsing, and ordering guidance. Retains KaKa's brand identity and standard minimum of 200 pieces per design.

The homepage uses the existing product imagery, product routes, resource routes, and quote form. New features: grouped desktop/mobile navigation, an interactive patch finder, backing selector, and a compact quote starter that carries the selected product and project details into the existing inquiry flow. No database, email, or attribution behavior is replaced.

The implementation avoids unsupported review scores, customer logos, prices, free sample promises, and shipping guarantees. Physical sample pricing and timing are confirmed for each project.

Preview product and quote links point to the existing kakapatches.com pages. The homepage design preview does not submit inquiries or collect uploads. In the Next.js implementation, links remain relative and use the established quote endpoint.
